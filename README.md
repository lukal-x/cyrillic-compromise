# Ukranian Cyrillic as a unifying compromise for all Cyrillic-compatible languages

The primary focus here is on strenghtening the position of the Cyrillic script, and this is an attempt to find a compromise between 
- West Slavic languages such as Polish, Czech (and others)
- South Slavic languages such as Bosnian-Croatian-Montenegrin-Serbian, Macedonian, Bulgarian (and others)
- East Slavic languages such as Russian, Belarusian
- but **also** without leaving out various language groups that aren't Slavic such as Greek, various Turkic, Caucasian, Persian, languages, Mongol, etc - all of which are compatible with the Cyrillic script

A starting point is actually figuring out a universal script which is accessible enough to everyone to use as a fallback while simultaneously acceptable-enough ideologically to everyone because - well - it works perfectly fine for everyone else.

So I'm not talking about changing a script anywhere, just experimenting with writing your own language with the Ukranian Cyrillic.

This could hypothetically completely bypass the problem of Russian (but also Germanic) imperialism as the biggest obstacle to to Cyrillic script.
If Serbs, Czechs, Poles, can all write in Ukrainian Cyrillic script to better understand each other - no one else has much room to complain, really.
